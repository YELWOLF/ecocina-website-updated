## ANIMATION CHOREOGRAPHY

### When a Project Enters the Viewport

**Timeline (all times in milliseconds):**

```
0ms  ├─ Overlay gradient fades in (opacity 0→1)
     │
100ms ├─ Location label slides up + fades in
      │  "MARRAKECH" appears with elegant serif
      │
100ms ├─ Project title appears
      │  "Terracotta Minimalism" animates in
      │
200ms ├─ Divider line scales in
      │  40px line reveals from left (scale: 0→1)
      │
250ms ├─ Detail grid appears
      │  Materials, Philosophy, Optimization, Details
      │  Grid items fade in + slide up
      │
300ms ├─ CTA button reveals
      │  "Discover My Process →" with hover state
      │
700ms └─ All animations complete, content fully visible
         ↓
       [User sees complete project information]
```

### Visual Easing Curve

```
Smooth, slightly anticipatory easing:
cubic-bezier(0.25, 0.1, 0.25, 1.0)

Translated to motion:
   ^
   │     ╱╱ Quick start (anticipatory)
   │    ╱ ╱ 
   │   ╱  ╱
1.0├─┴──╱────────── Smooth deceleration
   │   ╱         (elegant arrival)
   │  ╱
   │ ╱
 0 └─────────────────────── time
   0                       700ms
```

### Video Playback States

**Project In View:**
```
[VIDEO PLAYING]
  - Muted (required for autoplay)
  - Looping (continuous play)
  - Play button hidden (no controls visible)
  - ~8-12 seconds per loop
```

**Project Out of View (Above or Below):**
```
[VIDEO PAUSED]
  - Stops immediately
  - Preserves current frame
  - Ready to resume when scrolling back
  - Zero bandwidth while paused
```

## MOTION PRINCIPLES APPLIED

### 1. Purpose-Driven Animation
✅ Every motion serves a narrative function
❌ Never decorative or gratuitous

### 2. Smooth, Not Snappy
✅ 600-800ms durations feel premium
❌ 100-200ms feels rushed, cheap

### 3. Staggered Reveals
✅ 25-50ms delay between elements creates choreography
❌ All at once feels mechanical

### 4. Respects User Preference
✅ `prefers-reduced-motion: reduce` disables all animations
❌ Forced animations alienate users with vestibular disorders

### 5. Anticipatory Easing
✅ Easing curve has slight "anticipation" phase
❌ Linear or bouncy easing feels unrefined

## COMPETITIVE POSITIONING

### What Makes This Unique

**Traditional Portfolio:**
- Image grid
- Click to view
- Information static
- Forgettable

**This Portfolio:**
- Cinematic scroll
- Automatic reveal
- Narrative arc
- Memorable experience

### Why It Works for Luxury Kitchens

1. **Video = Proof** — Real projects, real craftsmanship
2. **Cinematic = Premium** — Matches luxury brand positioning
3. **Scroll = Control** — Users move at their own pace
4. **Details = Credibility** — Materials, philosophy shown
5. **Emotional = Conversion** — Desire leads to action

## TECHNICAL ELEGANCE

### Under the Hood (What Users Don't See)

```javascript
// Intelligent video management
When video enters viewport:
  → Play video (muted, for autoplay)
When video leaves viewport:
  → Pause video (save bandwidth)

// Scroll detection
Every 100ms during scroll:
  → Check which projects visible
  → Update progress dots
  → Manage animation states

// No dependencies
→ Pure HTML5 + CSS3 + JavaScript
→ 5KB of code (minified, gzipped)
→ No jQuery, no frameworks needed
```
